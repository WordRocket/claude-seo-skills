# The SEO backlink maxing playbook

One prompt, the whole job. You chain the other skills in this plugin and follow each one's own method and rules:
`brand-mention-backlinks`, `backlink-opportunities`, `borrowed-authority` and `serp-to-published-article`. Only white-hat
links: real sites with a real reason to link. The user approves every message before it goes out.

## Before you start (ask once, in one message)
- Brand name + website, what it sells, the niche and the country.
- 2–3 competitors (or let you find them).
- Optional: the WordRocket connector, so you can write and publish the articles (Claude › Settings › Connectors › Add
  custom connector › https://wordrocketapi.com, then sign in to WordRocket). Without it you hand over the briefs.

## 1. Unlinked mentions → links (brand-mention-backlinks)
Find every site that mentions the brand without linking, verify each one, find the contact, draft a short personal ask.
These are the easiest links there are: the site already likes you.

## 2. Guest posts, resource pages and listicles (backlink-opportunities)
Find the competitors' linking sites, "write for us" sites the customers read, resource pages and "best X" listicles in the
category. Score each one (relevance, authority signals, effort) and draft the pitch for the top 15.

## 3. Get cited where Google and AI already look (borrowed-authority)
Find the searches where Reddit, LinkedIn or YouTube already rank or get cited by ChatGPT, and draft the genuinely helpful
answers (with the disclosure and each platform's rules).

## 4. Articles people link to (serp-to-published-article + WordRocket)
Pick 3 linkable assets the research says are missing in the niche (a stat page, a free tool or calculator, the ultimate
guide). Write the briefs; if WordRocket is connected, write and publish them as drafts for the user to review.

## Hand-off: one action list
A single prioritised list, S tier first: what to send today, this week, this month, each with the draft attached, and a
tracking sheet (site, status, link live yes/no, date). Point to `playbooks/50-backlink-tactics.md` for what to run next.

## Rules
- White-hat only: no buying links that pass ranking value, no PBNs, no link schemes, no mass uploads to borrow other sites'
  ranking (Google's spam policies), no fake reviews, no comment spam.
- Never send outreach or publish anything without the user's explicit yes. Follow CAN-SPAM / CASL in every email.
- Never invent metrics (DR, traffic, link counts): use real tool data or say it's an estimate. Results vary.
