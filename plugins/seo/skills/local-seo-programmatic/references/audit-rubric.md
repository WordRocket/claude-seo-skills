# Local SEO Audit Scoring Rubric

Total possible score: 100 points across 5 categories (20 pts each).

---

## Category 1: On-Page Optimization (0–20 pts)

Award points based on what you find when crawling the site.

| Check | Points |
|---|---|
| Homepage title tag includes primary city/region | 3 |
| Homepage H1 or above-fold text mentions location | 2 |
| Dedicated service pages have location in title + H1 | 4 |
| Meta descriptions are written (not auto-generated) and include location | 2 |
| Images have descriptive alt text (including location where relevant) | 2 |
| NAP (Name, Address, Phone) is consistent across all pages | 4 |
| Contact/About page includes full address | 3 |

**Score guide:** 18–20 = excellent, 12–17 = needs work, below 12 = critical gaps

---

## Category 2: Site Structure (0–20 pts)

| Check | Points |
|---|---|
| Dedicated local/service-area pages exist (not just one generic "Service Areas" page) | 5 |
| URL structure is clean and includes location modifier (e.g. /hvac-dallas) | 3 |
| Internal links connect service pages to location pages | 3 |
| Location pages are indexed (not noindex'd, not blocked in robots.txt) | 4 |
| Site has a logical hub-and-spoke structure (service hub → city spokes) | 3 |
| XML sitemap includes local pages | 2 |

---

## Category 3: Google Business Profile (0–20 pts)

| Check | Points |
|---|---|
| GBP is claimed and verified | 5 |
| Business category is accurate and specific | 2 |
| 10+ reviews with a rating above 4.0 | 4 |
| Has responded to reviews (positive and/or negative) | 2 |
| Has recent GBP posts (within last 30 days) | 2 |
| Photos uploaded (at least 10, including real work photos) | 2 |
| Services/products list populated | 2 |
| Business description is written and keyword-rich | 1 |

---

## Category 4: Content Depth (0–20 pts)

| Check | Points |
|---|---|
| Local pages are at least 500 words (not thin content) | 4 |
| Content addresses local-specific questions or concerns | 3 |
| FAQ section present on service/local pages | 3 |
| Content mentions local neighborhoods, landmarks, or context | 3 |
| Testimonials or reviews embedded on local pages | 3 |
| Has blog/resource content targeting local search queries | 4 |

---

## Category 5: Technical SEO (0–20 pts)

| Check | Points |
|---|---|
| Site loads in under 3 seconds (estimate from fetch time / Core Web Vitals signals in source) | 4 |
| Site is mobile-friendly (viewport meta tag present, responsive layout) | 3 |
| HTTPS enabled | 2 |
| LocalBusiness schema markup present | 4 |
| No obvious crawl errors or broken internal links on key pages | 3 |
| Canonical tags correct on location pages | 2 |
| Hreflang tags if multi-language (or N/A if not applicable) | 2 |

---

## Score Interpretation

| Score | Status | What it means |
|---|---|---|
| 80–100 | Strong | Solid foundation; focus on expanding content and off-page |
| 60–79 | Moderate | Real gaps; structured improvement plan will move the needle |
| 40–59 | Weak | Multiple foundational issues; prioritize technical + structure fixes first |
| 0–39 | Critical | Starting from scratch effectively; biggest gains available here |

---

## Priority Impact Matrix

When writing the Top 5 To-Dos, rank actions by:

- **Impact** (High / Medium / Low) — how much will fixing this move rankings?
- **Effort** (Easy / Medium / Hard) — how long will it take?

Prioritize: High Impact + Easy effort first ("quick wins"), then High Impact + Medium effort, then the rest.

**Common high-impact local SEO actions:**
1. Build dedicated city/service-area pages (if none exist) — HIGH impact
2. Claim + optimize GBP — HIGH impact, relatively easy
3. Add LocalBusiness schema to homepage and location pages — HIGH impact, easy once known
4. Get NAP consistent across site and GBP — HIGH impact, medium effort
5. Build 10–20 programmatic local pages with unique content — HIGH impact, medium-high effort
6. Add location to title tags / H1s — HIGH impact, easy
7. Start getting reviews on GBP — HIGH impact, ongoing effort
